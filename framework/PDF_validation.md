## PDF validation is commonly required for:

- Policy documents
- Insurance statements
- Invoice downloads
- Bank statements
- Reports generated by applications
- Contract documents
- Regulatory documents

The most commonly used libraries are:

```xml
<!-- Apache PDFBox -->
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox</artifactId>
    <version>3.0.2</version>
</dependency>

<!-- PDFBox Tools (optional) -->
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox-tools</artifactId>
    <version>3.0.2</version>
</dependency>

```

# 1. Utility to Read Complete PDF Content
---

```java
import java.io.File;
import java.io.IOException;

import org.apache.pdfbox.Loader;
import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.text.PDFTextStripper;

public class PdfUtil {

    public static String getPdfText(String pdfPath)
            throws IOException {

        try (PDDocument document = Loader.loadPDF(new File(pdfPath))) {

            PDFTextStripper pdfStripper = new PDFTextStripper();

            return pdfStripper.getText(document);
        }
    }
}
```


Usage:
```java
String pdfText = PdfUtil.getPdfText("downloads/policy.pdf");

System.out.println(pdfText);
```

# Step 2. Verify Text Exists in PDF
---

```java
public static boolean containsText(
        String pdfPath,
        String expectedText)
        throws IOException {

    String pdfContent =
            getPdfText(pdfPath);

    return pdfContent.contains(expectedText);
}
```


# 3. Validate Multiple Text Values
---

```java
public static void verifyTexts(
        String pdfPath,
        List<String> expectedTexts)
        throws IOException {

    String pdfText =
            getPdfText(pdfPath);

    for(String text : expectedTexts) {

        if(!pdfText.contains(text)) {

            throw new AssertionError(
                    "Missing text : "
                            + text);
        }
    }
}

```

Usage:

```java
PdfUtil.verifyTexts(
        pdfFile,
        Arrays.asList(
                "Policy Number",
                "Customer Name",
                "Premium Amount"));

```


# 4. Read PDF Page Count
---

```java
public static int getPageCount(
        String pdfPath)
        throws IOException {

    try (PDDocument document =
                 Loader.loadPDF(
                         new File(pdfPath))) {

        return document.getNumberOfPages();
    }
}

```

Usage:

```java
Assert.assertEquals(
        PdfUtil.getPageCount(pdfFile),
        10);

```


# 5. Extract Text From Specific Page
---

```java
public static String getPageText(
        String pdfPath,
        int pageNo)
        throws IOException {

    try (PDDocument document =
                 Loader.loadPDF(
                         new File(pdfPath))) {

        PDFTextStripper stripper =
                new PDFTextStripper();

        stripper.setStartPage(pageNo);
        stripper.setEndPage(pageNo);

        return stripper.getText(document);
    }
}

```

Usage

```java
String page3Text =
        PdfUtil.getPageText(
                pdfFile,
                3);
```

# 6. Validate PDF Downloaded Successfully
---

```java
public static boolean waitForPdf(
        String folder,
        String fileName)
        throws InterruptedException {

    File file =
            new File(folder + "/" + fileName);

    int wait = 0;

    while(wait < 20) {

        if(file.exists()) {
            return true;
        }

        Thread.sleep(1000);
        wait++;
    }

    return false;
}

```

# 9. Validate PDF Contains Image

```java
public static boolean containsImages(
        String pdfPath)
        throws IOException {

    try(PDDocument document =
                Loader.loadPDF(
                        new File(pdfPath))) {

        for(var page : document.getPages()) {

            if(page.getResources()
                    .getXObjectNames()
                    .iterator()
                    .hasNext()) {

                return true;
            }
        }
    }

    return false;
}

```

Usage
```java
Assert.assertTrue(
        PdfUtil.containsImages(
                pdfFile));
```


#  10. Regex-Based Validation
---

Useful for policy numbers and invoice numbers.
```java
String pdfText =
        PdfUtil.getPdfText(pdfFile);

Pattern pattern =
        Pattern.compile(
                "POL\\d{5}");

Matcher matcher =
        pattern.matcher(pdfText);

Assert.assertTrue(
        matcher.find());
```

# 11. Data-Driven PDF Validation
---
```java
Map<String, String> expected =
        Map.of(
                "Customer Name",
                "John Smith",

                "Policy Number",
                "POL10001",

                "Status",
                "ACTIVE");
```

Validation Utility:

```java
public static void validatePdfData(
        String pdfFile,
        Map<String,String> expected)
        throws IOException {

    String pdfText =
            getPdfText(pdfFile);

    expected.forEach((k,v)->{

        if(!pdfText.contains(v)) {

            throw new AssertionError(
                    "Missing value : "
                            + v);
        }
    });
}
```
