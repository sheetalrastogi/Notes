# BOLA Test Scenarios Checklist

| Test | Description |
|--------|-------------|
| Horizontal Privilege Escalation | Access another user's object |
| Vertical Privilege Escalation | Access admin object |
| Cross-Tenant Access | Access another tenant data |
| Deleted Records | Access archived object |
| Hidden APIs | Direct API access |
| Mobile APIs | Modify object references |
| GraphQL IDs | Change object IDs |
| JWT userId Manipulation | Modify token claims |
| Batch APIs | Access multiple unauthorized records |
| Export Functions | Export another user's data |
| File Downloads | Download another user's document |
| Invoice Access | Access another customer's invoice |
| Order Access | Access another user's order |
| Claims Access | Access another customer's claim |
| Policy Access | Access another policyholder's policy |
