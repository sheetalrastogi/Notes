## Recommended Learning Path (QA / Test Automation Perspective)
- Prometheus Architecture and Core Concepts
- Metrics, Labels, Counters, Gauges, Histograms
- PromQL Basics
- Installing Prometheus
- Exporters (Node Exporter, JMX Exporter)
- Java Client Library
- Custom Metrics using Java
- Grafana Dashboards
- AlertManager
- Kubernetes Monitoring
- Application Monitoring
- API Monitoring (RestAssured + Prometheus + Grafana)
- SLI / SLO / SLA Monitoring
- Distributed Tracing Integration (Prometheus + OpenTelemetry + Grafana)


For your Selenium/RestAssured automation use case, Focus on:

- Counters
- Gauges
- Histograms
- PromQL
- Grafana Dashboards
- AlertManager
- Java Prometheus Client Library

These are sufficient to build enterprise dashboards for:

- API Availability
- Service Uptime/Downtime
- Error Rate
- Response Time (P95/P99)
- Transaction Success Rate
- AML Service Monitoring
- Selenium Execution Metrics
